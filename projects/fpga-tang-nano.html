FPGA Dev with Tang Nano

Overview

First steps into FPGA development on the Sipeed Tang Nano — a small Gowin-based board. Starting with the classics: getting an LED to blink from Verilog and understanding the toolchain end to end.

What I did

  • Set up Gowin IDE and the Tang Nano toolchain
  • Wrote basic Verilog for LED blink
  • Flashed the bitstream and verified on hardware
  • Next up: custom logic blocks and timing constraints
